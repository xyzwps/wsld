# shell

## Purpose
窗口外壳与几何:顶栏那一条、左侧导航、满应用的动作图标键,以及"该看得见的不许被裁"。
每个功能页自己呈现什么不在这里(见 `container-list.md`、`images.md`、`run-builder.md` 等)。

### Requirement: 顶栏那一条归应用画
系统标题栏收进来,窗口最上面那 46 DIP 是应用自己的顶栏:整条是拖拽区,左端品牌与当前页名,
右端主题快切与设置两颗键,再往右才是系统的最小化 / 最大化 / 关闭。
实测依据与折算细节见 `docs/notes/winui-shell.md`。

#### Scenario: SH-001 窗口最上面只有一条顶栏
- **WHEN** 打开主窗口
- **THEN** 窗口最上面那一条就是应用自己的顶栏,上面不压着操作系统的标题文字或标题栏按钮
- **AND** 顶栏左端读得到"wsld",紧跟着"· "加当前页的名字(如"· 容器")

#### Scenario: SH-002 拖顶栏就能拖窗口
- **WHEN** 按住顶栏空白处拖动
- **THEN** 整个窗口跟着走(顶栏整条都是拖拽区)
- **AND** 按住顶栏上的那颗键按下时,键正常响应而不是变成拖窗口

#### Scenario: SH-003 顶栏右端的键不与系统按钮叠在一起
- **WHEN** 在 Windows 上看顶栏右端
- **THEN** 应用那两颗键排在系统「最小化 / 最大化 / 关闭」的左边,互不遮挡
- **AND** 把窗口最大化,应用那两颗键仍在屏幕内,不跑到屏幕外
- **AND** 系统那三颗按钮竖着居中在顶栏这条带上,不靠上悬着

#### Scenario: SH-004 任务栏和读屏仍认得出这是 wsld
- **WHEN** 窗口开着,看任务栏或读屏软件报出的窗口名
- **THEN** 名字读得到"wsld"

### Requirement: 左侧导航切换页面不丢现场
四项功能页(容器 / 镜像 / 命令编排)加底部一项设置。页面实例常驻,切走再回来不重建、不重新加载。

#### Scenario: SH-005 导航里数得出这几项
- **WHEN** 看左侧导航栏
- **THEN** 依次读得到「容器」「镜像」「命令编排」三项,底部单独一项「设置」
- **AND** 界面里不出现框架自带的第二个"设置"入口

#### Scenario: SH-006 切页不重新加载
- **WHEN** 在容器页读到列表,切到镜像页再切回容器页
- **THEN** 容器页还是切走时那个样子:列表在、汇总在、搜索框里的字在
- **AND** 回来这一刻没有新起一次容器读取

#### Scenario: SH-007 顶栏齿轮直接落到设置页
- **WHEN** 点顶栏右端那颗设置键
- **THEN** 当前页切成设置页,顶栏的"· "后面跟着换成「设置」

#### Scenario: SH-008 导航栏能收能展
- **WHEN** 点顶栏左端那颗收展键
- **THEN** 左侧导航在展开与只剩图标之间切换,页面内容区跟着占满或让开
- **AND** 收起来的导航仍能点到各项

### Requirement: 动作键是图标,但念得出来
文字按钮会把行撑满(英文更长,日志页那一行曾被右边缘裁掉),图标换回横向空间。
代价是读屏与键盘用户看不见它是什么,所以**悬停说明与无障碍名称是强制项**,不是可选项。
样式档位与图标码点的约定见 `docs/notes/winui-shell.md`。

#### Scenario: SH-009 每颗纯图标键都有悬停说明
- **WHEN** 把鼠标停在任一颗纯图标键上(容器页、镜像页、日志页签、顶栏都算)
- **THEN** 弹出说明,说得出这颗键干什么(如"立即刷新容器列表""终止正在进行的拉取")
- **AND** 界面任何一处都不出现只有图标、悬停什么都不写的键

#### Scenario: SH-010 每颗纯图标键都念得出名字
- **WHEN** 用读屏软件或 UIA 树看这些键
- **THEN** 每颗键都带可读名称,不是类名或一串图标字符
- **AND** 切换界面语言后,这些名称跟着换成另一种语言

#### Scenario: SH-011 破坏性操作与主操作看得出区别
- **WHEN** 看容器详情区的四颗键与镜像页那颗删除键
- **THEN** 删除这类破坏性键用红色图标,启动/拉取这类主操作用强调色底
- **AND** 被拒绝过一次之后镜像那颗删除键的悬停说明变成"强制删除镜像引用 (wslc rmi -f)"

#### Scenario: SH-012 一行里不堆四颗键
- **WHEN** 看容器列表的任一行
- **THEN** 行内只有「启动」这一颗动作键
- **AND** 停止 / 重启 / 删除那三颗要在选中该行之后的详情区里

### Requirement: 该看得见的不许被裁
1180×780 的窗口下,中文与英文两种界面里都不许有控件被右边缘切掉、或挤成看不全的样子。
英文词条本身比中文短还是长,取决于表里的写法(见 `docs/notes/i18n-keys.md`)。

#### Scenario: SH-013 日志页那一行控件完整可见
- **WHEN** 1180×780 窗口、中文或英文界面,打开容器详情的「日志」页签
- **THEN** 「行数」下拉、「显示时间戳」「实时日志」「自动滚到底」这一整行都完整可见,不被右边缘裁掉
- **AND** 「行数」下拉选到最长那一档("最近 1000 行")时,框里的字仍读得全

#### Scenario: SH-014 下拉换语言不把工具栏宽度换来换去
- **WHEN** 中英两种界面之间切换,停在日志页
- **THEN** 「行数」那一格占的宽度不变,右边那几颗开关不因它变宽而被挤掉

#### Scenario: SH-015 页面内容超出高度时能滚到底
- **WHEN** 窗口高度不够装下整页内容(如详情区字段很长)
- **THEN** 这一页能竖向滚动,最底下那块(状态栏、说明文字)滚得到、看得见
- **AND** 横向不出现整页级别的滚动条

#### Scenario: SH-016 窗口拖到最小也版式不塌
- **WHEN** 把窗口拖到能拖的最小宽度
- **THEN** 左右两栏仍分得清,导航项、行内键、汇总文字都不叠在一起

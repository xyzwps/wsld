# i18n

## Purpose
界面语言:三档语言选择、切换之后界面怎么换干净、中英两套词条的一致性子。
主题档位在 `theme.md`,设置项怎么存盘读回在 `settings.md`。约定的由来见 `docs/notes/i18n-keys.md`。

### Requirement: 三档语言,选中即整窗换
#### Scenario: LANG-001 设置页数得出三档语言
- **WHEN** 打开设置页看「语言」
- **THEN** 读得到「跟随系统」「简体中文」「English」三个选项,当前生效的那一档是选中态
- **AND** 这一组下面读得到"当前界面语言:简体中文"(或"当前界面语言:英文"),以及"系统语言没有对应文案时用英文。"

#### Scenario: LANG-002 选 English 整窗立刻变英文
- **WHEN** 把语言从简体中文改选 English
- **THEN** 导航项、顶栏的"· 当前页"、各页标题、按钮悬停说明、列表里的状态文字(如"运行中"→"Running")全部换成英文
- **AND** 不需要关窗口再打开

#### Scenario: LANG-003 跟随系统只认中文,其余一律英文
- **WHEN** 语言停在「跟随系统」
- **THEN** 操作系统显示语言是中文时用中文界面
- **AND** 操作系统是英文或任何一种别的语言时用英文界面,不给那门语言硬凑半套词条

#### Scenario: LANG-004 语言这一档活到下次启动
- **WHEN** 选定某一种语言后关掉应用再打开
- **THEN** 启动即用这一档语言呈现,设置页的选中态也在同一档

### Requirement: 换语言要换得干净
静态文案烧在页面里,只换导航与顶栏会留下半中半英,所以换语言时当前页整页重建。
重建为什么不能当场做、为什么要先停掉实时日志,见 `docs/notes/i18n-keys.md`。

#### Scenario: LANG-005 换完不出现半中半英
- **WHEN** 在容器页或镜像页换过语言
- **THEN** 这一页从头到脚都是新那门语言,没有哪一处标签、哪一句提示还留着旧语言

#### Scenario: LANG-006 换完页面照常可用
- **WHEN** 换语言的当场接着点(刷新、搜索、选一行看详情)
- **THEN** 界面不崩、不空页,容器与镜像照常列出来(重新读到的一份)

#### Scenario: LANG-007 换语言不留一个没人看的进程
- **WHEN** 日志页的实时日志正在跑,此时换语言
- **THEN** 实时日志先停下来,本机不留下挂着的 `wslc` 进程
- **AND** 换完再进日志页签,页签状态读得到"没在跟随"

#### Scenario: LANG-008 换语言时正有操作在跑不塌
- **WHEN** 有一次容器操作或镜像拉取正在进行,此时换语言
- **THEN** 界面不崩,该操作的互斥状态仍说得清(不许出现"两个操作同时在跑"的错觉)

### Requirement: 一句文案都不许只有一种语言
中英两套词条的键必须一模一样、占位符一模一样、不许空值;这条由测试钉住,不是靠人记。

#### Scenario: LANG-009 英文界面里不残留中文词条
- **WHEN** 用英文界面把每一页逐块看一遍
- **THEN** 任何一处提示、说明、占位文案都读得到英文,没有哪一句因为"英文表里没这条"而退回中文显示
- **AND** 中文界面反过来同样不残留英文

#### Scenario: LANG-010 缺词条宁可露出键名
- **WHEN** 某句文案在当前语言表里查不到(而中文表里也没有)
- **THEN** 界面把那个键名原样显示出来,让人一眼看见漏翻在哪儿
- **AND** 不显示空白、不崩

#### Scenario: LANG-011 带数字的句子里数字填得进去
- **WHEN** 两种语言界面下各看一条带数字的汇总(如"共 3 个容器 · 1 个运行中")
- **THEN** 数字出现在句子里该在的位置,两种语言都不出现没被替换的占位符,也不丢数字

#### Scenario: LANG-012 数字写法不跟着语言加千分位
- **WHEN** 日志页「行数」选到 1000 那一档
- **THEN** 框里读得到"最近 1000 行"(英文 `1000 lines`),不是带千分位的写法

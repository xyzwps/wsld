# 功能 009 · 设置页(主题 / 语言 i18n)与界面改版

状态:已完成(2026-10-12,含真机验证)
相关:功能 003(左侧导航)、功能 005(日志页工具栏防裁切的布局约定)

## 是什么

三件事,都是"界面层"的:

1. **重做顶条**:接管系统标题栏,自绘一条 46 DIP 高的顶栏 ——
   左边是"收展导航 + 品牌图标 + `WSLC Desktop · 当前页`",右边是"主题快切 + 设置"两个图标键,
   再往右才是系统的最小化 / 最大化 / 关闭。
2. **动作按钮全部换成图标**:容器页 4 个(启动 / 停止 / 重启 / 删除)、镜像页 4 个
   (拉取 / 取消 / 刷新 / 删除)、日志页 3 个(刷新容器列表 / 加载日志 / 停止跟随)、
   顶栏 3 个(收展导航 / 主题 / 设置)。每个图标都同时带悬停说明和无障碍名称。
3. **新增第四页"设置"**:主题(跟随系统 / 浅色 / 深色)、语言(跟随系统 / 简体中文 / English)、
   关于(应用版本、`wslc.exe` 路径、设置文件位置)。选完立即生效并写盘,没有"保存"按钮。

顺带把全应用文案抽进 `Localizer`:中英两套、125 个键,系统语言不是中文时自动落到英文。

## 为什么

**顶条**:原来是"系统标题栏 + 页面里再来一个大标题",两条标题叠在一起,
窗口高度白吃掉一截,深色模式下两条的颜色还不一致。

**图标按钮**:一行四个文字按钮("启动 停止 重启 删除")就把列表行撑满,
换成英文更长("Start / Stop / Restart / Delete"),日志页工具栏更是直接被右边缘裁掉。
图标 + 悬停说明能把横向空间还回来 —— 但纯图标对读屏软件和鼠标键盘用户是灾难,
所以 ToolTip 和 `AutomationProperties.Name` 是强制项,不是可选项。

**i18n + 设置页**:文案烧在 XAML 里意味着"想换语言就得改代码重编译"。
`wslc` 本身就有中英文两套输出,界面跟着系统显示语言走才不别扭;
而主题和语言既然是"用户能改的东西",就需要一个地方存下来、并在下次启动时读回来。

## 实测到的行为(本规格的依据)

| 主题 | 实测结论 |
|---|---|
| 接管标题栏 | `AppWindow.TitleBar.ExtendsContentIntoTitleBar = true` + `SetTitleBar(元素)` 即可;`SetTitleBar` 给的那个元素整块成为拖拽区 |
| 系统按钮留白 | `TitleBar.RightInset` 是**物理像素**,要除以 `XamlRoot.RasterizationScale` 才能当 XAML 的 DIP 用;窗口最大化时系统内容区还会再内缩 8 DIP,不留出来按钮会跑到屏幕外 |
| 系统按钮高度 | 顶栏加高到 46 DIP 后,必须同时设 `PreferredHeightOption = Tall`,否则最小化/关闭按钮靠上、自绘按钮居中,视觉上错位 |
| `Window` 根上的绑定 | 编译限制:`x:Bind` + 转换器无法在 `Window` 根元素上生成代码 → 顶栏和导航项的文案只能在代码里赋值 |
| 主题生效范围 | `Root.RequestedTheme` 设 Light / Dark / Default,`Default` 就是"跟随系统";但 `Window` 自身的底色不跟 `Root` 变,必须显式给 `Background`,否则浅色模式下导航区透出深色底、整片发黑 |
| ComboBox 宽度 | 控件的 UIA `BoundingRectangle` **把下拉的占位一起算进去**:固定 150 DIP 的"行数"下拉,UIA 报的是 237×95;不给固定宽度时它按内容要宽(实测英文 107 DIP、中文 124 DIP)。判断"要不要限宽"只能看闭合状态的渲染截图 |
| 数字文案 | `string.Format(InvariantCulture, "{0}", 1000)` → `"1000"`(默认 G 格式不带千分位),所以列表里是"最近 1000 行"而不是"最近 1,000 行" |
| 带 BOM 的设置文件 | 记事本 / Visual Studio 会把 `settings.json` 存成带 BOM 的 UTF-8,`JsonSerializer` 视 BOM 为非法字符 → 异常被 `catch` 吞掉,现象是"设置被莫名其妙重置" |
| 构建输出目录 | `Platforms=x64` 时,走解决方案构建输出到 `bin\x64\Debug\...`,直接构建单个项目输出到 `bin\Debug\...`,两份并存;自动化脚本必须挑 `LastWriteTime` 最新的那个,否则测的是旧 exe |

## 预期行为(验收条件)

### AC1 · 自定义标题栏
系统标题栏收进来,顶栏整行(≥46 DIP)是拖拽区;右侧动作区按 `RightInset / RasterizationScale`
让开系统按钮,最大化时再补 8 DIP。`Window.Title` 仍然是 `WSLC Desktop` ——
系统标题栏虽然被接管,任务栏和 UIA 还要靠它认窗口名。

### AC2 · 设置持久化
写在 `%LOCALAPPDATA%\WslcDesktop\settings.json`,字段 `Theme` / `Language`,枚举序列化成可读名字。

- 文件不存在、JSON 坏掉、没有写权限 → 一律返回默认值(跟随系统 + 跟随系统),**绝不抛异常**;
- 保存失败只是"没存住",界面照常工作;
- 读的时候容忍:带 UTF-8 BOM、带注释、带尾逗号、大小写不同的属性名、将来新增的未知字段;
- `AppSettings` 新增字段必须给默认值,老配置文件才读得动。

### AC3 · 主题
三档:跟随系统 / 浅色 / 深色。改完立即生效(根元素换主题 + 系统标题栏按钮换配色),不需要重启。
顶栏的太阳 / 月亮键在"浅色 ↔ 深色"之间来回切(当前是深色就切到浅色),并把结果同步回设置页的选中态。

### AC4 · 图标按钮
四套统一样式:`IconOnlyButtonStyle`(普通)、`AccentIconButtonStyle`(主操作)、
`DangerIconButtonStyle`(破坏性操作,红色图标)、`TitleBarIconButtonStyle`(顶栏扁平键);
图标码点集中在 `App.xaml` 的 `IconFont`(Segoe MDL2 Assets)。

**每个纯图标按钮必须同时提供 `ToolTipService.ToolTip` 和 `AutomationProperties.Name`**,
且两者都走 Localizer —— 少一个就是"读屏软件念不出这是什么按钮"或"换语言后残留另一种语言"。
镜像页的删除按钮在被"占用拒绝"过一次之后语义升级为强制删除,tooltip 要跟着状态变
(`ImageItemViewModel.RemoveTooltip`)。

### AC5 · 语言
三档:跟随系统 / 简体中文 / English。跟随系统 = `CultureInfo.CurrentUICulture` 的两字母代码是 `zh`
就取中文,**其余一律 fallback 到英文**。

- 中英两套文案的**键集合必须完全一致**、占位符一致、不允许空值(有测试钉住);
- 缺键时退回中文,再缺就把键名原样显示出来,让漏翻一眼看得见;
- 日期/数字按 `zh-CN` / `en-US` 报 locale,但 `Fmt` 内部用 `InvariantCulture` 格式化数字。

### AC6 · 换语言立即生效
`Localizer.LanguageChanged` → 主窗口先 `ApplyTexts()`(导航项、tooltip、页标题),
再 `RebuildPages()` 整页重建 —— 静态文案烧在页面里,只有重建才换得干净。
重建必须排队到下一帧:语言单选按钮的 `Checked` 事件还在调用栈上,当场拆可视树不安全;
重建前若日志页正在跟随,先 `CancelFollow()`,不能留下一个没人看的孤儿 `wslc` 进程。

### AC7 · 设置页交互
选中即生效、即存盘,没有"保存"按钮(少一步,也免得改了没存)。
构造时回填选中态会触发 `Checked`,用 `_loading` 标记挡住"自己保存自己";
外部(顶栏主题键)改过设置后调 `RefreshFromState()`,否则会出现"界面已经是浅色,选项还停在跟随系统"。

### AC8 · 关于卡片
显示:应用版本(`AssemblyInformationalVersion`,去掉 `+commit` 后缀)、
`wslc.exe` 定位结果(定位失败显示"未找到"而不是空)、设置文件的完整路径(方便用户去找它)。

### AC9 · 设置入口
设置项放在 `NavigationView.FooterMenuItems`,与三个功能页分开;
顶栏齿轮键 = 直接跳到设置页;`IsSettingsVisible="False"`,避免框架自带的"设置"和自建的入口打架。

### AC10 · 工具栏不溢出
1180×780 窗口下,中文和英文两种界面里:日志页"行数 + 显示时间戳 + 实时跟随 + 自动滚动"一整行、
容器页与镜像页的行内操作按钮组都不被右边缘裁切。"行数"下拉固定 150 DIP
(够放最长条目,且中英切换时工具栏宽度不跳)。

### AC11 · 不破坏已有功能
001–005 的 242 项断言写的仍是改版前的中文原句 —— 靠 `TestEnvironment` 的
`[ModuleInitializer]` 把测试语言钉成简体中文,否则测试结果会跟着测试机器的系统语言变。
文案抽取不改变任何业务行为。

### 真机验证暴露并已修复的问题

1. **带 BOM 的 `settings.json` 被当成"设置被重置"**:记事本存出来的文件带 BOM,JSON 解析异常被
   兜底 `catch` 吞掉,现象是"我明明选了深色,重启又变回跟随系统"。读取前先 `TrimStart('\uFEFF')`
   (开发笔记 #22)。
2. **日志页英文界面下拉裁字**:为了"够宽"给下拉设过固定宽度之后,又发现文案本身
   (`Last 200 lines` / `Show timestamps`)在窄窗口里挤掉了右边的开关;英文表改成
   `200 lines` / `Timestamps`,中文表刻意保持与改版前逐字一致(001–005 的断言依赖它,AC11)。
3. **截图四边混进背景窗口**:`GetWindowRect` 和 DWM 扩展帧边界外面都还包着约 2px 的不可见
   调整热区,截图前要在 DWM 边界基础上再 inset 2px(开发笔记 #25)。

# theme

## Purpose
外观主题:整窗的深浅色从哪一档决定、改完要不要重启、顶栏那颗快切键与设置页那三项怎么保持一致。
存盘与读回的契约在 `settings.md`,换语言在 `i18n.md`。

### Requirement: 三档主题,选中即生效
设置页「外观」那一档给三个选择,没有"保存"这一步。约定的由来见 `docs/notes/winui-shell.md`。

#### Scenario: TH-001 设置页数得出三档主题
- **WHEN** 打开设置页看「主题」
- **THEN** 读得到「跟随系统」「浅色」「深色」三个选项,当前生效的那一档是选中态
- **AND** 这一组下面读得到"改完立即生效,并保存在本机。"

#### Scenario: TH-002 选一档立刻换皮,不用重启
- **WHEN** 停在任一页面上把主题从当前档改选另一档
- **THEN** 整窗当场换成新那一档的颜色,不需要关窗口再打开
- **AND** 换皮期间列表内容、正在进行的容器操作都不受影响

#### Scenario: TH-003 跟随系统就是操作系统的档
- **WHEN** 主题选「跟随系统」,操作系统处于深色(或浅色)
- **THEN** 整窗跟着操作系统那档呈现,界面自己不做第二套判断

#### Scenario: TH-004 四种组合都读得清
- **WHEN** 深色 / 浅色 × 中文 / 英文 四种组合下逐页走查(容器、镜像、日志、命令编排、设置)
- **THEN** 每一页的正文、次要说明、状态点、输入框里的占位文案都读得清,没有"深底深字"或"浅底浅字"
- **AND** 这一条只能真机看,属人工检查清单

### Requirement: 换皮要换全,不能只换一半
主题设在页面根上,而窗口自己的底色与操作系统那三颗按钮的配色各是独立的一处;
少给一处就会出现"浅色模式下导航区黑成一片"或"标题栏按钮看不见"。依据见 `docs/notes/winui-shell.md`。

#### Scenario: TH-005 导航区与顶栏一起换
- **WHEN** 切到浅色
- **THEN** 左侧导航区、顶栏、页面内容区都是浅色,没有哪一块还留着深色底
- **AND** 切到深色时反过来,没有哪一块还留着浅色底

#### Scenario: TH-006 系统那三颗按钮的配色跟着换
- **WHEN** 切换主题后看顶栏右端的「最小化 / 最大化 / 关闭」
- **THEN** 这三颗的图标与悬停、按下时的配色都跟当前那一档一致,不会在深色标题栏里出现看不清的深色图标

### Requirement: 顶栏给一颗快切键
这颗键只在浅色与深色之间来回切,它切的是"实际呈现的那一档";切完要把结果同步回设置页。

#### Scenario: TH-007 点它就在深浅之间来回
- **WHEN** 当前呈现深色,点顶栏那颗主题键
- **THEN** 整窗换成浅色,那颗键的图标换成对应浅色那档的样子;再点一次换回深色
- **AND** 悬停说明报的是**当前**这一档("主题:浅色"或"主题:深色"),不是说要点过去的那一档
- **AND** 档位停在「跟随系统」且实际是浅色时,那颗键的悬停说明读得到"主题跟随系统"

#### Scenario: TH-008 「跟随系统」时按实际呈现的那档切
- **WHEN** 主题停在「跟随系统」而操作系统是深色,点顶栏那颗键
- **THEN** 切到「浅色」这一档(而不是回到"跟随系统"),整窗立刻变浅

#### Scenario: TH-009 顶栏切完,设置页的选中态跟上
- **WHEN** 用顶栏那颗键换过主题,再进设置页
- **THEN** 「主题」那三项里选中的是刚切过去的那一档
- **AND** 不出现"界面已经是浅色,选项还停在跟随系统"

#### Scenario: TH-010 从设置页改主题,顶栏那颗键跟着变
- **WHEN** 在设置页把主题从「深色」改选「浅色」
- **THEN** 顶栏那颗键的图标与悬停说明都换成浅色那一档的样子

### Requirement: 主题这一档活到下次启动
选完写进本机的设置文件,下次打开应用还是这一档(读写与容错的契约在 `settings.md`)。

#### Scenario: TH-011 重启后还是这一档
- **WHEN** 选定「深色」后关掉应用再打开
- **THEN** 启动即深色,设置页的选中态也在「深色」

#### Scenario: TH-012 存的是能读懂的名字
- **WHEN** 用户用文本编辑器打开设置文件看主题那一行
- **THEN** 存的是这一档能读懂的名字(如 `Dark`),不是某个数字编号
